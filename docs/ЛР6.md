# Лабораторная работа 6. Импорт логов и обход графа

## Что сделано
1. **Шаблонный метод:** Создан абстрактный класс `LogImporterBase`, который задает скелет алгоритма импорта (Чтение -> Парсинг -> Фильтрация -> Форматирование -> Запись). Конкретные шаги реализуются в наследниках.
2. **Стратегия:** Реализованы две конкретные стратегии импорта:
   - `PlainTextLogImporter` (с парсером `PlainTextLogParser` для формата `[дата] УРОВЕНЬ сообщение`).
   - `JsonLogImporter` (с парсером `JsonLogParser` для JSON-строк).
3. **Итератор:** Реализован кастомный итератор `LogIterator` и коллекция `LogCollection` для обхода записей лога без раскрытия внутреннего представления.
4. Настроена DI-регистрация для всех новых компонентов.

## Диаграмма классов
Код PlantUML: [lr6.puml](lr6.puml)
